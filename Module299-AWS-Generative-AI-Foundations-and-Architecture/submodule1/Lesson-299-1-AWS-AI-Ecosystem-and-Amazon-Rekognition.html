1.1 The AWS AI Ecosystem at a Glance

  • AWS offers AI services at several levels. Some let you use ready-made AI capabilities. Others give you more control to build, train, deploy, and operate your own models.
  • Which service you use depends on four things: what you are trying to do, how much choice you need in the foundation models that you use, how much customization your generative AI application needs, and the expertise in your organization.
  • AI services rarely run alone. They use other AWS services around them for data, compute, access control, and monitoring.

2.1 Generative AI and Foundation Models

  • Generative AI creates new content, such as text, images, code, and summaries, from an instruction that you give it.
  • A foundation model (FM) is a very large model that was trained on broad data, so it can do many tasks without a new model for each one.
  • A prompt is the instruction and the context that you send to the model. A token is a small piece of text, and Bedrock bills text models by the number of tokens of input and output.
  • The context window is how much text a model can take into account in one request.
  • A model can sound sure and still be wrong. This is called a hallucination, and this tab shows how to reduce it.

2.2 What Amazon Bedrock Is

Amazon Bedrock belongs to the managed generative AI platforms. This category provides API-driven access to high-performing foundation models (FMs) from leading AI providers and Amazon, without requiring infrastructure setup or model hosting.

  • Amazon Bedrock is a fully managed, serverless platform for building generative AI applications and agents with foundation models. Developers access models from Amazon and other model providers through managed APIs, without deploying or managing the underlying servers.
  • It supports more than 100 foundation models from providers that include Amazon (Amazon Nova), Anthropic (Claude), DeepSeek, Moonshot AI, MiniMax, OpenAI, and xAI. Which models you can use depends on the Region. Amazon Bedrock Marketplace adds more than 100 other models to discover and test.
  • You reach the models through the console, the AWS SDKs, and the bedrock-runtime endpoint, which AWS recommends for new applications.

Bedrock supports capabilities such as:

  • Text and content generation.
  • Summarization.
  • Conversational assistants.
  • Image generation.
  • Embeddings.
  • Retrieval augmented generation.
  • Model evaluation and customization.
  • AI agents and workflows.
  • Responsible AI controls.

2.6 Grounding With Knowledge Bases

  • A foundation model knows only what it saw in training. Retrieval augmented generation (RAG) fetches the most relevant passages from your own data before the model answers, so the answer is grounded in your documents and can name its sources. You do not retrain anything: when a document changes, you sync the data again.
  1. Connect a data source, most often an Amazon S3 bucket.
  2. Bedrock parses the documents, splits them into chunks, turns each chunk into an embedding, and writes the vectors to a vector store, such as Amazon OpenSearch Serverless.
  3. At run time, the question is turned into an embedding, and the knowledge base retrieves the closest chunks.
  4. The foundation model receives the question and the chunks, and writes an answer with citations.
  • Retrieve returns the relevant chunks, with their source and a relevance score. RetrieveAndGenerate retrieves the chunks and calls the model to write the answer in one operation.
  • Use RAG for facts that change, such as policies. Use fine-tuning to teach a tone, a format, or a skill, and repeat it when the data changes.

2.7 Guardrails

  • Guardrails for Amazon Bedrock lets you implement safeguards for your generative AI application, based on your policies.
  • It checks both the user’s input and the model’s output. A prompt or a response that breaks a rule is blocked or masked.
  • Typical controls are content filters for harmful content, denied topics, word filters, filters for sensitive information such as personal data, checks that the answer is grounded in the retrieved source, and automated reasoning checks that help reduce factual errors.
  • It works with any model invocation in Bedrock, including calls that Knowledge Bases and agents make, and it can check text from models outside Bedrock.

2.8 Agents and Amazon Bedrock AgentCore

  • A chat answer is one response to one prompt. An agent works out the steps that a goal needs, calls tools and APIs, retrieves business information, keeps the context of the session, and acts on behalf of a user.
  • Amazon Bedrock AgentCore is an agentic platform to build, deploy, and operate agents securely at scale, with any framework and any foundation model, in or outside Bedrock. Its services work together or on their own.
  • Runtime hosts the agent serverless, with isolated sessions. Identity gives secure access to AWS resources and third-party tools, on behalf of users or on its own. Memory keeps short-term and long-term context.
  • Gateway turns APIs, Lambda functions, and services into tools that agents can use. Observability traces and monitors the agent with Amazon CloudWatch. Policy keeps the agent’s actions inside rules that you set.
  • AgentCore has consumption-based pricing with no upfront commitment.

2.9 Customization and Cost

  • Move up the ladder only when you need to: prompt engineering first, then RAG, then model customization (fine-tuning, continued pre-training, distillation, or reinforcement fine-tuning), then custom model import, and Amazon SageMaker AI for maximum control.
  • On-demand inference is billed per token of input and output, with service tiers for Priority, Flex, and Reserved. Batch inference can save up to 50 percent for work that nobody waits for, and Provisioned Throughput gives committed capacity at reduced rates for steady traffic.
  • Use a smaller model for simple tasks, shorter prompts, and prompt caching, which AWS says can cut cost by up to 90 percent for supported models. Knowledge Bases, Guardrails, and Data Automation are priced separately. Prices change, so check the pricing page.
Exam trap

Do not rely on a prompt alone for answers about your own policies. A model can state wrong facts with confidence, so ground it with a knowledge base and add a guardrail. A guardrail is not a prompt instruction: it checks every input and output outside the model. Also, do not run non-urgent work at on-demand prices when batch inference can save up to 50 percent.

Memory hook

Bedrock lends you the model. RAG gives it the facts. Guardrails guard the door.

3. Introduction to Amazon Rekognition

Problem Statement

FlashCart Inc. lets sellers upload photos of the products they sell. Last month, customers reported photos that were inappropriate for a shopping site, and many photos have no tags, so search results are poor.

The engineering manager wants automatic checks on every upload. The team has no machine learning engineers, and the manager does not want to train or host models.

She also asks what the team must prepare before it can call the service.

Your challenge: Advise the manager. Your answer should:

  • Explain what Amazon Rekognition does and why it needs no machine learning expertise.
  • List what the images and the Region must look like before the team calls the API.

3.1 What Amazon Rekognition Is

  • Amazon Rekognition is a cloud-based image and video analysis service. It adds computer vision to an application through a simple API.
  • It is fully managed and comes pre-trained, so you do not build, train, or host a deep learning model.
  • It finds objects, scenes, people, faces, text, celebrities, and inappropriate content in images and videos.
  • It analyzes images and videos that are stored in Amazon S3. You can also send an image as bytes in the request.
  • AWS keeps improving the models and adding labels and features, so results can change over time.

3.2 How You Call Rekognition

  • You send an API request that names the image, and Rekognition returns a JSON response with results and confidence scores.
  • You can pass an image as an object in an Amazon S3 bucket, or as image bytes. The S3 bucket must be in the same Region as the Rekognition API endpoint.
  • Access uses AWS Identity and Access Management (IAM) policies, so only authorized users and roles can call the APIs.
  • You can use the AWS Management Console, the AWS SDKs, or the AWS Command Line Interface (AWS CLI).

4. Image Analysis with AI

Problem Statement

FlashCart’s marketing team wants every product photo tagged with what it shows, so that shoppers can search by objects and colors. The trust and safety team wants unsafe photos flagged before they reach the site, and a person must look at the doubtful cases.

The warehouse team has a third request. Photos from the packing floor should show whether pickers wear head covers and face covers, and some photos include shipping labels that must be read.

The architect knows that each feature returns a confidence score, and she must decide how strict the checks should be.

Your challenge: Match the needs to Rekognition features. Your answer should:

  • Name the feature for tags, unsafe content, protective equipment, and text in photos.
  • Explain what a confidence score is and how a minimum confidence threshold changes the results.
  • Say how doubtful moderation results reach a person.

4.1 Label Detection

  • A label is an object, scene, or concept found in an image. A beach photo can return Person, Water, Sand, and Palm Tree (objects), Beach (a scene), and Outdoors (a concept).
  • The DetectLabels API finds thousands of objects, scenes, and concepts and returns a confidence score for each one. Its default confidence threshold is 50.
  • For many common objects, such as Person, Car, and Dog, it also returns a bounding box for each instance.
  • For each label, it returns the parent labels, the aliases, and the category. For example, a Car has the parents Vehicle and Transportation.
  • Image Properties returns dominant colors (10 by default, up to 12) and brightness, sharpness, and contrast scores from 0 to 100.

4.2 Confidence Scores and Thresholds

A confidence score is a number from 0 to 100 that shows how likely a prediction is to be correct. A label with a score of 99 is far more likely to be right than a label with a score of 35.

SettingEffectUse it when
Lower minimum confidenceMore detections, including more false positives.Missing a result is costly, and a person reviews the output.
Higher minimum confidenceFewer false positives, but some real items are not returned.Wrong results are costly, such as automatic actions on user content.

The MinConfidence parameter sets the minimum score for a request. AWS advises that, in many cases, the best user experience comes from minimum confidence values that are higher than the default.

4.3 Content Moderation

  • Content moderation detects explicit or suggestive adult content, violent content, weapons, visually disturbing content, drugs, alcohol, tobacco, hate symbols, gambling, and rude gestures in images and videos.
  • It returns a hierarchy of labels, such as a top-level label and a more specific second-level label, each with a confidence score. You can build different filtering rules for different regions or audiences.
  • Set a minimum confidence threshold for the items that you flag.
  • Many designs send results below a confidence threshold to a person for review, so that a human makes the final call on doubtful cases.
  • You can customize the output of the moderation API with adapters that you train on your own images.
  • The moderation API is not an exhaustive filter, and it does not detect illegal content, such as child sexual abuse material.

4.4 Text in Images

Rekognition can detect text in images and videos and convert it into machine-readable text. The DetectText API does this for images, and Rekognition Video does it for stored video.

4.4.1 Use Cases for Text in Images

  • Visual search: find and show images that contain the same text.
  • Content insights: find themes in text that is recognized in frames taken from a video. An application can search the recognized text for news, sports scores, athlete numbers, and captions.
  • Navigation: build a speech-enabled mobile app for people with low vision that reads the names of restaurants, shops, and street signs.
  • Public safety and transportation: read license plate numbers in traffic camera images.
  • Filtering: find and remove personally identifiable information (PII) from images.

4.4.2 Use Cases for Text in Videos

  • Search videos for clips that contain specific words, such as a guest’s name on a news graphic.
  • Moderate content against organizational standards by finding accidental text, profanity, or spam.
  • Find every text overlay on the video timeline for further processing, such as replacing the text with a translation for another language.
  • Find where text appears, so that other graphics can be aligned around it.

To be detected, text must be within 90 degrees either way of the horizontal axis, which is why the tilted word Smiling is still found.

4.4.4 Settings and Limits

  • Text detection is built for real-world scenes, such as street names, captions, product names, and license plates. It can also read key text on a photo of an ID card (section 4.7), but forms and tables belong to Amazon Textract.
  • It supports most Latin scripts and numbers, in many fonts and layouts.
  • It recognizes up to 50 sequences of characters in an image or video frame, and lists them as words and lines.
  • You can limit detection to up to 10 regions of interest, and filter by minimum confidence or bounding box size.

For more detailed information, see text detection in the Amazon Rekognition Developer Guide.

4.5 Face Detection and Analysis

  • The DetectFaces API detects up to 100 faces in an image and returns a bounding box, facial landmarks, face pose, face quality, and attributes such as sunglasses and apparent emotions.
  • Rekognition Video returns detected faces with timestamps, positions, and landmarks.
  • Emotions describe only the physical appearance of a face. AWS states that they are not a determination of a person’s internal emotional state and should not be used that way.
  • Gender predictions are binary and are based on the physical appearance of a face in a particular image.

For more detailed information, see Detecting and analyzing faces in the Amazon Rekognition Developer Guide.

4.6 Face Comparison

  • The CompareFaces API measures the likelihood that faces in two images are the same person.
  • It compares one face in the source image with up to 15 detected faces in the target image, and returns a similarity score for each pair.
  • If the source image has several faces, it uses the largest face.
  • A typical use is to verify a person against a photo on file.

4.8 Celebrity Recognition

  • The RecognizeCelebrities API recognizes people who are famous, noteworthy, or prominent in categories such as politics, sports, business, entertainment, and media.
  • It can identify only the celebrities that the models were trained to recognize. It is not an exhaustive list.
  • A celebrity can ask AWS Customer Support to be removed from the feature.

4.9 Protective Equipment Detection

  • The DetectProtectiveEquipment API detects common face covers, hand covers, and head covers on people in images, with bounding boxes and confidence scores.
  • It returns a CoversBodyPart value, which shows whether the item is on the matching body part. It does not show that the person is adequately protected or that the item is worn properly.
  • It does not identify the people in the image.
  • For items such as high-visibility vests and safety goggles, you can use Rekognition Custom Labels.

4.10 Custom Labels and Adapters

  • Custom Labels trains a model to find objects and scenes that are specific to your business, such as logos or machine parts. It is not designed for analyzing faces or for custom text detection.
  • A distinct logo can need only one or two training images. A subtle logo that appears in many variations can need tens to hundreds.
  • You pay for a custom model while it is started. Start it when you need it, and stop it when you are done. A failed training run is not charged.
  • Adapters let you improve the accuracy of some image analysis APIs, such as content moderation, by training on your own sample images.

The two requests look alike, but the team suspects that they need different Rekognition features. The legal team adds a warning: faces are biometric data, and several laws require notice and consent.

The architect must choose the right features and explain how the stored face data works.

Your challenge: Design the face features. Your answer should:

  • Explain when to use face comparison and when to use face search.
  • Describe what a face collection stores, and the calls that fill it and search it.
  • State two privacy actions that FlashCart must take.

5.2 Face Collections

  • A face collection is your searchable index of face vectors, which are mathematical representations of faces. Rekognition does not store images of faces in the collection.
  • CreateCollection creates a collection in a Region and returns an Amazon Resource Name (ARN). Each collection has a unique CollectionId.
  • IndexFaces adds the faces that it detects in an image to the collection, and returns a unique FaceId for each face vector.
  • SearchFacesByImage searches with an image, and SearchFaces searches with a FaceId. Both return matches ordered by similarity, highest first.
  • You can also group the faces of one person as a user vector, and search with SearchUsersByImage or SearchUsers.
  • DeleteFaces removes faces, and DeleteCollection removes the whole collection.

5.3 The Face Search Workflow

  1. Create the collection with CreateCollection.
  2. Index each employee photo with IndexFaces.
  3. When a visitor arrives, search with SearchFacesByImage.
  4. Your application reads the similarity score and decides what to do, for example by opening the door above a threshold that you choose.

5.4 Getting Better Matches

  • Index several images of each person, with variations such as glasses, a beard, and frontal and profile poses.
  • Use sharp, well-lit images. Heavy blur, fast movement, and poor lighting lower quality.
  • Keep faces large enough in the frame. As a rule of thumb, the smallest face should be at least 5 percent of the shorter image dimension.
  • Choose a similarity threshold that fits the risk of a wrong match, and add a second check for high-stakes decisions.

5.5 Face Liveness

Rekognition Face Liveness is a fully managed feature that helps developers deter fraud during face-based identity verification. It checks that a live person is present. It can detect spoofs shown to the camera, such as printed photos, digital photos, digital videos, and 3D masks, and spoofs that bypass the camera, such as pre-recorded or deepfake videos. Section 4.7 shows where liveness fits in an identity verification workflow.

The graphic below walks through the user flow: the instructions, the liveness check, and the returned result.

5.5.1 How Face Liveness Works

A liveness check uses several components. The user records a short video selfie and follows prompts that confirm that a real person is in front of the camera.

Component or APIWhat it does
AWS Amplify SDK with the FaceLivenessDetector componentAvailable for React, Swift (iOS), and Android. It shows the user interface and real-time feedback while the user records the selfie video, and it streams the video securely to the cloud APIs.

5.5.2 What You Get Back

  • A confidence score from 0 to 100. The higher the score, the greater the confidence that the person taking the check is live.
  • A high-quality reference image that you can use for face comparison and face search, for example with CompareFaces and SearchFacesByImage.
  • Up to four audit images that Rekognition selects from the selfie video.
  • One or more feedback codes for low-confidence sessions, so that you can show retry guidance to the user.
  • The score comes from a probability calculation, so it cannot guarantee a perfect result. Use it with other factors to make a risk-based decision about a user’s identity.

5.5.3 Choosing the Challenge and the Thresholds

  • FaceMovementAndLightChallenge: the user moves the face into an oval, and the screen shows a sequence of colored lights. AWS describes it as the best setting for accuracy.
  • FaceMovementChallenge: the user moves the face into the oval, with no colored lights. It favors a faster check over accuracy.
  • The light challenge flashes colors, so the flow starts with a photosensitivity warning, as Image 5b shows.
  • Choose the challenge from your use case: the attacks you expect, the false accept and false reject rates you can accept, and other checks that you add, such as IP-based location or one-time passcodes. Test different confidence thresholds on your own content before you decide.
  • Set thresholds for the liveness score and for the face match score. If the user is above both, approve. If not, ask the user to try again or offer another method.
  • Secure the device that sends the video stream.
  • Liveness is often used with face matching for identity verification, with age estimation on sites that restrict access by age, and to detect real users while deterring bots.

5.6 Privacy and Biometric Laws

  • Face data is biometric data. Biometrics laws can require that you give notice, get consent, and honor deletion requests.
  • Under the shared responsibility model, you decide what applies to your service. This lesson is not legal advice.
  • You can delete vectors with DeleteFaces or DeleteCollection.
  • AWS publishes responsible AI guidance and AI Service Cards for some Rekognition features.
  • You are charged for face vectors that you store, and the charge is per month. Check the pricing page for the current rate.

6.1 Stored Video Analysis

  • Rekognition Video analyzes videos that are stored in Amazon S3. The video must use the H.264 codec in an MPEG-4 or MOV file, up to 10 GB and 6 hours.
  • The operations are asynchronous. A Start operation begins the job and returns a JobId at once. It does not return results.
  • When the job finishes, Rekognition publishes a completion status to the Amazon SNS topic that you named in the request. A role that you supply gives Rekognition permission to publish to that topic.
  • If the status is SUCCEEDED, you call the matching Get operation with the JobId to read the results.

6.2 Reading the Results

Label results can be organized in two ways. By timestamp, each label is returned every time it is detected, so a Dog at 2,000 and 4,000 milliseconds gives two entries. By segment, a label found in consecutive frames is returned once, with a start, an end, and a duration.

6.3 Segment Detection for Media Analysis

  • Segment detection is an asynchronous API, StartSegmentDetection and GetSegmentDetection.
  • It can detect black frames, opening and closing credits, shots, color bars, slates, studio logos, and the program content itself.
  • It gives frame-accurate SMPTE timecodes, as well as millisecond timestamps, for frame rates from 15 to 60 frames per second.
  • You can set a minimum confidence for each segment type, and tune the black frame settings.
  • Editors use it to place ads, create “Skip Intro” markers, and trim files before publishing.

6.4 Video Quality Tips

  • Faces must be larger than 32 pixels on the shorter side to be recognized.
  • Blur, fast movement, poor lighting, and unusual poses lower quality.
  • The service works best with consumer and professional video that has a frontal view and normal color and lighting. It is not tested on black and white, infrared, or extreme lighting.

7. Architecture, Security, and Cost

Problem Statement

FlashCart is ready to build the upload check. Every product photo that a seller uploads must be analyzed within seconds, and unsafe or doubtful photos must not go live. The team wants to avoid servers that run all day.

The security team asks who can call the service, what AWS does with the images, and how to keep costs predictable. The finance team asks how Rekognition is billed.

The architect must draw the pipeline and answer both teams.

Your challenge: Design the pipeline. Your answer should:

  • Show how an upload leads to analysis, storage of results, and a review step for doubtful results.
  • Describe how access, data privacy, and logging work.
  • Explain the billing model and two ways to control cost.

7.1 An Event-Driven Moderation Pipeline

  1. A seller uploads an image to an Amazon S3 bucket in the same Region as Rekognition.
  2. The upload event starts an AWS Lambda function. Rekognition can be called directly from Lambda in response to S3 events.
  3. The function calls DetectModerationLabels and DetectLabels with a minimum confidence that fits the use case.
  4. The function stores the results, for example in Amazon DynamoDB, and publishes the image only if the checks pass.
  5. Results below the confidence threshold go to a review queue, where a person on your team decides.

There are no servers to manage. The design scales with the number of uploads, and you pay for the work that is done.

7.2 Security and Access Control

  • Use IAM policies and roles to control who can call Rekognition. Give the Lambda function a role with only the Rekognition actions it needs, such as rekognition:DetectLabels, and read access to the bucket.
  • Rekognition supports AWS CloudTrail logging for management actions, such as CreateCollection and DeleteCollection. Check the documentation for the full list.
  • AWS says that it protects your content with encryption at rest and in transit, and that only authorized employees can access it.
  • You always own your content. You can ask AWS Support to delete the image and video inputs that Rekognition stored.

7.3 Data Privacy and the AI Services Opt-Out

  • Rekognition may store and use the images and videos that it processes to provide the service, and, unless you opt out, to improve Rekognition and other Amazon AI technologies.
  • To opt out, use an AWS Organizations AI services opt-out policy.
  • AWS does not use personally identifiable information in your content to target products, services, or marketing at you or your users.

7.4 Responsible Use

  • Moderation is not an exhaustive filter, and it does not detect illegal content. Use human review for doubtful and high-impact decisions.
  • Emotion results describe the look of a face and are not a measure of how a person feels.
  • Use face features with notice, consent, and a clear deletion process. Follow the biometrics laws that apply to you.
  • Measure accuracy on your own data before you rely on the results, as AWS recommends.

8.5 Lesson Summary

  • Rekognition Image detects labels, text in scenes, faces, celebrities, protective equipment, and unsafe content. Every result has a confidence score, and the minimum confidence you set balances missed items against false positives.
  • CompareFaces is one-to-one. A face collection supports one-to-many search, and it stores face vectors, not images. Face data needs notice, consent, and a deletion process.
  • Stored video analysis is asynchronous: Start, the SNS completion status, and then Get.
  • A typical design uses an S3 event, a Lambda function, Rekognition, and a review queue for doubtful results. The bucket and the API must be in the same Region.

9. Knowledge Check

Answer each question in your own words before you open the model answer.

  1. Explain what Amazon Rekognition is, and why FlashCart can use it with no machine learning engineers.

    Show the model answer

    Rekognition is a fully managed image and video analysis service with pre-trained deep learning models. FlashCart calls an API with an image from Amazon S3 or as bytes and reads a JSON response with results and confidence scores. AWS builds, trains, hosts, and improves the models, so the team needs no machine learning expertise.

  2. Where does Rekognition sit among the three layers of AWS AI and machine learning, and what does that mean for effort and control?

    Show the model answer

    It sits in the top layer, the AI services, with Amazon Polly, Amazon Transcribe, Amazon Textract, Amazon Translate, Amazon Comprehend, and Amazon Connect. AWS does the heavy lifting, so effort is lowest, but control over the model is limited. The middle layer, Amazon SageMaker AI, is for building your own models, and the bottom layer is infrastructure and frameworks for experts.

  3. What is a confidence score, and how does the minimum confidence setting change results?

    Show the model answer

    A confidence score is a number from 0 to 100 that shows how likely a prediction is to be correct. A lower minimum confidence returns more detections but also more false positives. A higher minimum confidence returns fewer false positives, but real items can be missed. The right value depends on the cost of each kind of error.

  4. How would you moderate seller photos at FlashCart, and how do people fit in?

    Show the model answer

    Use Rekognition content moderation through DetectModerationLabels, with a minimum confidence that fits the policy. Results below a chosen threshold are sent to a review queue, where a person on your team decides. Remember that moderation is not an exhaustive filter and does not detect illegal content, so people review doubtful and high-impact cases.

  5. When do you use DetectText in Rekognition, and when do you use Amazon Textract?

    Show the model answer

    DetectText is for text in real-world scenes, such as street signs, product names, and license plates. Amazon Textract is for documents, such as scanned forms and tables, where you need text and data. Choose by the type of input: scenes for Rekognition, documents for Textract.

  6. Explain the difference between CompareFaces and face search. Which would you use to verify a seller, and which for employee entry?

    Show the model answer

    CompareFaces is one-to-one: it measures whether faces in two images are the same person, so it fits verifying a seller against a document photo. Face search is one-to-many: you index faces into a collection with IndexFaces and search it with SearchFacesByImage, so it fits employee entry. A collection stores face vectors, not face images.

  7. What privacy actions does a face-based solution need?

    Show the model answer

    Face data is biometric data, so give notice, get consent, and handle deletion requests as the laws that apply to you require. You can delete vectors with DeleteFaces or DeleteCollection. Use human review for high-stakes matches, and measure accuracy on your own data.

  8. Describe the steps of a stored video analysis job.

    Show the model answer

    Store the video in Amazon S3 in an H.264 MP4 or MOV file. Call a Start operation, such as StartLabelDetection, which returns a JobId. Rekognition runs the job asynchronously and publishes a completion status to the Amazon SNS topic that you named. When the status is SUCCEEDED, call the matching Get operation with the JobId.

  9. Draw the architecture for moderating every upload with no servers to manage, and name the access controls.

    Show the model answer

    A seller uploads an image to an Amazon S3 bucket in the same Region as Rekognition. An S3 event starts an AWS Lambda function, which calls Rekognition and stores the results, for example in Amazon DynamoDB. Low-confidence results go to a review queue for people. The Lambda function uses an IAM role with only the Rekognition and S3 permissions it needs, and CloudTrail records management actions.

  10. How is Rekognition billed, and what are two ways to control cost?

    Show the model answer

    Image APIs are billed by the number of images analyzed, stored video by the minutes processed, and face vectors by a monthly storage charge. Custom Labels is billed while a model is started. To control cost, analyze each image once at upload and store the results, and stop custom models and delete collections that are no longer in use.

  11. What does AWS do with the images that Rekognition processes, and how can an organization opt out?

    Show the model answer

    Rekognition may store and use images and videos to provide the service and, unless you opt out, to improve Rekognition and other Amazon AI technologies. You keep ownership of your content. To opt out, use an AWS Organizations AI services opt-out policy, and ask AWS Support if you need stored inputs deleted.
